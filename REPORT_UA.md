# Звіт: Amazon Reviews, Apache Spark та MongoDB

## Сформульована задача
Побудувати масштабований ETL-пайплайн для Amazon Reviews: зчитати CSV через Apache Spark, очистити дані, залишити лише verified purchase reviews, виконати агрегування та зберегти результати в MongoDB для швидких аналітичних запитів.

## Виконані агрегації
1. `product_review_stats`: кількість відгуків і середній рейтинг для кожного товару.
2. `customer_review_counts`: кількість verified-відгуків для кожного користувача.
3. `product_monthly_reviews`: помісячна кількість відгуків і середній рейтинг для кожного товару.

## Оптимізація MongoDB
- `product_review_stats`: індекс за `product_id` для швидкого отримання статистики товару.
- `customer_review_counts`: індекс за `customer_id` для швидкого пошуку активності користувача.
- `product_monthly_reviews`: складений індекс `(product_id, review_month)` для трендового аналізу.

## Результати на наданому CSV
- Всього рядків у файлі: 396000.
- Рядків після очищення і фільтрації verified purchases: 46823.
- Найбільше verified-відгуків має товар `0439784549` — 256 відгуків, середній рейтинг 4.4492.

## Висновок
Spark-підхід кращий за прості Python-скрипти для великих даних, бо обробка виконується розподілено, операції очищення та агрегації описуються декларативно через DataFrame API, а результати одразу записуються в MongoDB у форматі, оптимізованому під типові запити.
